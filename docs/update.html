Nivra 1.7.1 is here

Here is what changed in this update. Your settings were kept.

Local PDFsPDFs saved on your computer only open in Nivra after you switch on Allow access to file URLs for Nivra on your browser's extensions page. Nivra's toolbar icon shows a red ! until it is on. Paste that address into the address bar; browsers block links to it.
FirefoxClick the Nivra icon and choose Allow site access if you have not yet, so PDF links open in Nivra. PDFs saved on your computer stay in Firefox's viewer; drop one on the Nivra popup to read it in Nivra.

What's new

Newest first. The release you just got is highlighted.

1.7.1 · latest

  • Local files made easy. Right after install a setup window shows whether local PDFs are switched on, red until they are, and turns green by itself once you do it.
  • A red ! badge on the toolbar icon, and a red banner in the popup, while the step is still missing.
  • Firefox: the same window asks for site access, which Firefox needs before Nivra can open PDF links.
  • This page: Nivra now opens it after every update so you can see what changed.
  • The goodbye page has a working feedback form.

1.7.0

  • Opera and Firefox. Nivra now works in Opera and in Firefox (web PDF links; Firefox keeps local files in its own viewer).
  • One version number for every browser: Edge, Chrome, Opera and Firefox all ship the same release.
  • Opera and Edge get a fallback for when the browser's own PDF viewer opens first.

1.6.1

  • Edge PDF fallback, a file-access banner in the popup, and the welcome and goodbye pages.

Help
